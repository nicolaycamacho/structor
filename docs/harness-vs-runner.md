# Harness vs Runner

The harness defines what must be true. A runner decides when and how work is
executed.

## Harness

- policy
- contracts
- context routing
- task templates
- review rules
- validation expectations
- quality tracking

## Runner

- polling
- agent sessions
- branch and PR automation
- CI shepherding
- dashboards
- repair loops
- external writes

The template creates harness repositories. It does not create a runner.
